# OrionSplit

Программа для удаления диалогов (вокала) из аудио.
Автор: **Ilya Lavrin**.

- Движок разделения вшит внутрь — ничего стороннего ставить не нужно.
- **Модель кладётся в папку `models`** рядом с программой и подхватывается
  автоматически.
- Открывает всё: wav, flac, mp3, m4a, aac, а также видео (mkv, mp4, avi…) —
  через вшитый ffmpeg.
- Для видео спрашивает, какую **звуковую дорожку** взять. Если дорожка
  **5.1 и выше** — предлагает разложить её **по каналам** отдельными файлами
  (диалоги обычно в центральном канале C). Стерео и моно обрабатываются
  одним файлом.
- Рендер по умолчанию на **GPU (CUDA)**, в настройках переключается на CPU.
- Движок грузится в фоне при добавлении файла — окно открывается сразу.

## Запуск из исходников

```
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
python app.py
```

> **Видеокарты RTX 50xx (Blackwell, sm_120)** требуют сборку torch с
> **CUDA 12.8** (`cu128`). На старом `cu121` будет ошибка
> «no kernel image is available for execution on the device».

## Сборка exe

Запусти `build_gpu.bat` (или `build_cpu.bat`). PyInstaller соберёт
`dist\OrionSplit\`, затем скрипт удалит четыре неиспользуемые CUDA-библиотеки
(−496 МБ). Модель положи в `dist\OrionSplit\_internal\models\`.

### Почему стоит держать модель в .safetensors

`.ckpt` на 430M параметров весит 1.6 ГБ и читается ~3 с. fp16-safetensors —
820 МБ и ~0.2 с, при расхождении 0.0003 % на основном стеме. Конвертация:

```
python tools\convert_model.py models\модель.ckpt
```

### Про размер и холодный старт

torch на Windows принудительно грузит **все** dll из своей папки
(`torch\__init__.py`: `glob("*.dll")` → `LoadLibraryExW`), поэтому лишние
библиотеки замедляют первый запуск. Удалены только те, от которых никто не
зависит — проверено разбором таблиц импорта PE и полным прогоном инференса.
Остальные (cublas, cudnn, cufft, cusolver, cusparse) жёстко нужны
`torch_cuda.dll`, а движки cuDNN подгружаются динамически — их не трогать.

## Инструкция для пользователя

1. Распакуй архив, запусти `OrionSplit.exe`.
2. Перетащи аудио или видео в окно.
3. Для видео выбери дорожку и, если это 5.1, — разбивать ли по каналам.
4. Нажми **РЕНДЕРИТЬ**. Повторное нажатие останавливает обработку.
5. Результат появится рядом с исходником (при разбивке — в подпапке
   `имя_channels`). Кнопка **ПАПКА ↗** откроет её.

## Настройки (⚙)

- **Устройство** — GPU (CUDA) по умолчанию / CPU
- **Формат вывода** — WAV 32f, WAV 24-bit, FLAC 24-bit
- **Режим** — Качество (по умолчанию) или Быстро (~2× быстрее за счёт
  меньшего перекрытия чанков)
- **Модель** — по умолчанию берётся из папки `models`. Кнопка
  **ЗАГРУЗИТЬ МОДЕЛЬ…** подключает свою (скачанную отдельно): укажи файл
  `.safetensors` или `.ckpt`, конфиг `.yaml` подхватится из той же папки.
  **СБРОС** возвращает модель из `models`.

Настройки хранятся в `%APPDATA%\OrionSplit\config.json`. Путь к модели из
папки `models` там не хранится — она ищется заново при каждом запуске;
запоминается только подключённая вручную.
