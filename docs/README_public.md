## Что это

OrionSplit разделяет фонограмму на **инструментал** (без голоса) и **голос**.
Основное применение — снять дубляж или закадровый голос с фильма и оставить
чистую музыку с эффектами, либо наоборот вытащить речь.

Внутри — модель **Mel-Band RoFormer** (InstVox Duality v2) и собственный
движок инференса. Никаких сторонних оболочек ставить не нужно: Python,
PyTorch, CUDA и FFmpeg уже внутри сборки.

## Возможности

- **Аудио и видео.** wav, flac, mp3, m4a, aac, ogg, opus, а также mkv, mp4,
  avi, mov и другие контейнеры.
- **Выбор звуковой дорожки.** Для видео программа покажет все дорожки с
  языком, названием и раскладкой — выбираешь нужную.
- **Разбивка 5.1 по каналам.** Если дорожка многоканальная, можно обработать
  каждый канал отдельным файлом — диалоги обычно живут в центральном канале
  **C**, и это позволяет снять их точечно, не трогая остальные. Стерео и моно
  обрабатываются одним файлом.
- **Пакетная обработка** с очередью, прогрессом и оценкой оставшегося времени.
- **Остановка в любой момент** — повторное нажатие кнопки прерывает рендер.
- **Две модели в комплекте, переключаются в настройках:**
  - **Mel-Band RoFormer InstVox Duality v2** — музыкальная, отделяет вокал
    от инструментала. Оформление программы оранжевое.
  - **Bandit v2** — обучена именно на кино (датасет Divide and Remaster v3),
    делит звук на **речь / музыку / эффекты** и понимает шумовые эффекты как
    отдельную сущность. Музыка и эффекты складываются обратно в одну
    дорожку, так что на выходе те же два файла. Работает на родных для
    кино 48 кГц без ресемплинга. Оформление переключается на зелёное.
- **Свои модели.** Кнопка **ЗАГРУЗИТЬ МОДЕЛЬ…** подключает любую скачанную
  (`.safetensors` или `.ckpt` вместе с её `.yaml`). Активная модель видна
  в подвале окна.

## Установка

В [релизе](../../releases/latest) два файла — нужны оба.

1. Скачай **`OrionSplit-2.6-win64.7z`** и распакуй куда угодно
   (путь без кириллицы надёжнее). Нужен [7-Zip](https://www.7-zip.org/)
   или WinRAR.
2. Скачай **`melband_roformer_instvox_duality_v2.safetensors`** и положи его
   в папку `OrionSplit\_internal\models\` рядом с уже лежащим там
   `config_*.yaml`.
3. Запусти `OrionSplit.exe`.

Должно получиться так:

```
OrionSplit\
├── OrionSplit.exe
└── _internal\
    └── models\
        ├── config_melbandroformer_instvoc_duality.yaml   ← уже в архиве
        └── melband_roformer_instvox_duality_v2.safetensors ← скачиваешь
```

Установщика нет и не нужно — программа полностью переносимая.
Модель лежит отдельно, потому что GitHub не принимает файлы больше 2 ГБ.

**Требования:** Windows 10/11 x64. Для GPU-режима — видеокарта NVIDIA
(GTX 16xx и новее) со свежим драйвером. CUDA Toolkit ставить **не надо**.
Без NVIDIA программа сама переключится на процессор — медленнее, но работает.

## Как пользоваться

1. Перетащи файлы в окно (или нажми на зону, чтобы выбрать).
2. Для видео выбери звуковую дорожку. Если она 5.1 — реши, разбивать ли по
   каналам.
3. Отметь, что нужно на выходе: **Инструментал**, **Голос** или оба.
4. Жми **РЕНДЕРИТЬ**.

Результат появится рядом с исходником: `имя_instrumental.flac` и
`имя_vocals.flac`. При разбивке по каналам — в подпапке `имя_channels`.
Кнопка **ПАПКА ↗** откроет её.

## Настройки

| Параметр | Значения |
|---|---|
| **Устройство** | GPU (CUDA) по умолчанию · CPU |
| **Формат вывода** | WAV 32-bit float · WAV 24-bit · FLAC 24-bit |
| **Режим** | Качество (по умолчанию) · Быстро — примерно вдвое быстрее за счёт меньшего перекрытия чанков |
| **Модель** | Список всех найденных моделей с переключением между ними |

Настройки лежат в `%APPDATA%\OrionSplit\config.json`. Папка `models`
сканируется заново при каждом запуске — чтобы добавить модель, достаточно
положить туда её файлы.

## Скорость

Замеры на RTX 5060 (Blackwell), 60 секунд стереофонограммы:

| Режим | Время | Быстрее реального времени |
|---|---|---|
| Качество | 13.4 с | ×4.5 |
| Быстро | 6.9 с | ×8.8 |

Полуторачасовой фильм в режиме «Качество» обрабатывается примерно за
20 минут на канал. Скорость сильно зависит от видеокарты.

Движок не грузится при запуске — окно открывается сразу, а модель
подтягивается в фоне, как только добавлен первый файл.

## Частые вопросы

**Программа не запускается / вылетает сразу.**
Скорее всего не хватает Microsoft Visual C++ Redistributable — поставь
[свежий пакет](https://aka.ms/vs/17/release/vc_redist.x64.exe).

**Ошибка «no kernel image is available for execution on the device».**
Видеокарта слишком старая для этой сборки CUDA (нужна GTX 16xx или новее).
Переключись в настройках на CPU.

**Первый запуск очень долгий.**
Windows впервые читает с диска около 2 ГБ библиотек. Последующие запуски —
пара секунд.

**Долго висит на первом файле.**
Это прогрев: загрузка модели и подготовка ядер CUDA. Дальше пойдёт быстро.
