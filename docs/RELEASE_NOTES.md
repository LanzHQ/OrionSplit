# OrionSplit v2.6

Удаление диалогов из аудио и видео. Портативная сборка под Windows x64 —
распаковал и запустил, ничего доустанавливать не нужно.

## Что умеет

- Делит фонограмму на **инструментал** (без голоса) и **голос**
- Открывает аудио (wav, flac, mp3, m4a, aac, ogg, opus) и видео
  (mkv, mp4, avi, mov…) — FFmpeg вшит внутрь
- Для видео даёт **выбрать звуковую дорожку** — со списком языков и раскладок
- **Разбивает 5.1 по каналам** отдельными файлами: диалоги обычно в
  центральном канале **C**, его можно обработать точечно
- Очередь файлов, прогресс с оценкой времени, остановка в любой момент
- Подключение **своих моделей** Mel-Band RoFormer через настройки

## Установка

Ниже **два файла — нужны оба**. Модель лежит отдельно, потому что GitHub
не принимает вложения больше 2 ГБ.

1. Скачай **`OrionSplit-2.6-win64.7z`** и распакуй в любую папку
   (путь без кириллицы — надёжнее). Понадобится
   [7-Zip](https://www.7-zip.org/) или WinRAR.
2. Скачай **`melband_roformer_instvox_duality_v2.safetensors`** и положи
   в `OrionSplit\_internal\models\` — там уже лежит её `config_*.yaml`.
3. Запусти `OrionSplit.exe`.

```
OrionSplit\
├── OrionSplit.exe
└── _internal\models\
    ├── config_melbandroformer_instvoc_duality.yaml   ← уже в архиве
    └── melband_roformer_instvox_duality_v2.safetensors ← скачиваешь
```

Если модель не положить, программа скажет «Положи модель… в папку models».

## Требования

- Windows 10/11 x64
- Для GPU: видеокарта NVIDIA GTX 16xx или новее, свежий драйвер.
  **CUDA Toolkit ставить не нужно** — всё внутри
- Без NVIDIA работает на процессоре (в настройках), просто медленнее
- Если программа не стартует — поставь
  [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)

## Известные особенности

- **Первый запуск после распаковки долгий** (до минуты) — Windows читает
  с диска библиотеки CUDA. Дальше запуск занимает пару секунд.
- Первый файл в очереди обрабатывается дольше остальных: идёт загрузка
  модели и прогрев ядер CUDA.
- Видеокарты старше GTX 16xx GPU-режим не поддерживают — переключись на CPU.

## Что внутри

Mel-Band RoFormer (InstVox Duality v2), PyTorch с CUDA 12.8, PySide6, FFmpeg.
FFmpeg распространяется под GPL и вызывается как отдельная программа.
